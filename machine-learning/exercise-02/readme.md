# Exercise 2

## Overview

This exercise introduces pandas for tabular data analysis in Python, focusing on DataFrame/Series basics and core operations.

Content is based on the [Kaggle Learn pandas tutorial](https://www.kaggle.com/learn/pandas).

## Files

- `pandas/` - pandas resources.
  - `tutorial/` - concept notebooks.
    - `1-creating-reading-and-writing.ipynb` - creating, reading, and writing DataFrames/Series.
    - `2-indexing-selecting-assigning.ipynb` - indexing, selecting, and assigning data.
  - `exercise_solutions/` - solved exercise notebooks.
    - `1-exercise-creating-reading-and-writing.ipynb` - exercise solutions for creation/read/write tasks.
    - `2-exercise-indexing-selecting-assigning.ipynb` - exercise solutions for indexing/selection tasks.
  - `input/` - datasets used by notebooks.
    - `wine_reviews/`
      - `winemag-data-130k-v2.csv` - wine review dataset.
    - `youtube-new/`
      - `CAvideos.csv` - Canada YouTube trending data.
      - `GBvideos.csv` - Great Britain YouTube trending data.
