# Exercise 4

## Overview

This exercise introduces classical machine learning algorithms in scikit-learn:
- **Classification**: 0R, logistic regression, Naive Bayes, k-NN, decision tree, random forest.
- **Regression**: linear regression, decision tree regressor, random forest regressor.

Models are trained and evaluated on synthetic datasets to build intuition through visual feedback.

Official documentation: [scikit-learn](https://scikit-learn.org/stable/index.html).

## Files

- `classification_models.ipynb` - classification models notebook.
- `regression_models.ipynb` - regression models notebook.
- `utils.py` - helper utilities for dataset generation and plotting.
