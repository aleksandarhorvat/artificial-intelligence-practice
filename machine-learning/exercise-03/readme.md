# Exercise 3

## Overview

This exercise continues pandas practice and introduces basic visualization with seaborn.

Most material comes from:
- [Kaggle Learn pandas](https://www.kaggle.com/learn/pandas)
- [Kaggle Learn data visualization](https://www.kaggle.com/learn/data-visualization)

## Files

- `pandas/` - pandas resources.
  - `tutorial/`
    - `3-summary-functions-and-maps.ipynb` - summary functions and mapping (`map`, `apply`).
    - `4-grouping-and-sorting.ipynb` - grouping and sorting techniques.
    - `5-data-types-and-missing-values.ipynb` - data types and missing value handling.
    - `6-renaming-and-combining.ipynb` - renaming and combining DataFrames.
  - `exercise_solutions/`
    - `3-exercise-summary-functions-and-maps.ipynb` - summary/mapping exercise solutions.
    - `4-exercise-grouping-and-sorting.ipynb` - grouping/sorting exercise solutions.
    - `5-exercise-data-types-and-missing-values.ipynb` - missing values/data types exercise solutions.
  - `input/`
    - `wine_reviews/`
      - `winemag-data-130k-v2.csv` - wine review dataset.
    - `youtube-new/`
      - `CAvideos.csv` - Canada YouTube trending data.
      - `GBvideos.csv` - Great Britain YouTube trending data.
- `seaborn/` - data visualization resources.
  - `tutorial/`
    - `1-hello-seaborn.ipynb` - seaborn introduction and setup.
    - `2-line-charts.ipynb` - line chart examples.
    - `3-bar-charts-and-heatmaps.ipynb` - bar chart and heatmap examples.
    - `4-distributions.ipynb` - distribution plot examples.
    - `5-scatter-plots.ipynb` - scatter plot examples.
  - `exercise_solutions/`
    - `seaborn-solutions.ipynb` - visualization exercise solutions.
  - `input/` - datasets used by seaborn notebooks.
  - `Kinds of Data Visualizations.png` - chart types overview.
