# Exercise 6

## Overview

This exercise focuses on binary classification for the Titanic dataset.

Topics covered:
- tabular preprocessing,
- train/test splits,
- model comparison,
- k-fold cross-validation,
- hyperparameter tuning,
- evaluation metrics (accuracy, precision, recall, F1).

The Titanic competition dataset is available on Kaggle: [Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic/overview).

## Files

- `titanic/` - main Titanic exercise folder.
  - `titanic_solution.ipynb` - primary exercise notebook (partially completed).
  - `titanic_dataset/` - Titanic training/test datasets.
- `iris/` - optional simpler practice task.
  - `iris_solution.ipynb` - Iris task notebook.
  - `iris_dataset/` - Iris datasets.
