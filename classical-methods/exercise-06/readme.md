# Exercise 6

## Overview

This exercise implements Minimax for Connect 4, then improves it with alpha-beta pruning and depth-limited search.

## Files

- `exercise_06.md` - problem statement.
- `connect_4_problem/` - templates and solutions for the exercise.
- `connect_4_problem/template/` - starter template.
- `connect_4_problem/basic_minimax_solution/` - plain Minimax solution (best for small board sizes).
- `connect_4_problem/optimized_minimax_solution/` - optimized solution with alpha-beta pruning and depth limits.
