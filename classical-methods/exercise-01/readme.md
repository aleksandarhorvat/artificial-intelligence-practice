# Exercise 1

## Overview

This exercise introduces basic Python syntax and core data structures.

## Files

- `intro.py` - basic Python syntax and data types.
- `conditions_and_loops.py` - examples of conditions and loops.
- `functions.py` - examples of Python functions.
- `data_structures.py` - operations with lists, tuples, sets, dictionaries, deque, and priority queues.
- `files.py` - file operation examples.
- `sample.txt` - sample input file for `files.py`.
- `Problems/` - directory with solved practice problems.
