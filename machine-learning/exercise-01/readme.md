# Exercise 1

## Overview

This exercise introduces machine learning workflows and foundational tools.

The sequence is:
1. Set up the shared conda environment.
2. Get familiar with Jupyter notebooks (including VS Code integration).
3. Learn NumPy basics for scientific computing.

## Files

- `conda/` - materials for conda package management.
  - `conda-cheatsheet.pdf` - commonly used conda commands.
  - `conda_setup.md` - setup guide for the exercise environment.
  - `env.yml` - conda environment definition.
- `jupyter_notebooks/` - introductory notebook materials.
  - `notebook.ipynb` - basic Jupyter usage examples.
- `numpy/` - NumPy learning materials.
  - `numpy.ipynb` - NumPy examples notebook.
